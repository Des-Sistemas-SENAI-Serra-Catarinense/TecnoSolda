# Dados autorizados

Não há imagens de pessoas neste protótipo. A simulação produz evidências tipadas.
Não adicionar vídeos, imagens pessoais ou datasets ao repositório público.

A próxima fase deve registrar autorização, licença, retenção e responsáveis pela
coleta; separar treino, validação e teste por pessoa autorizada/gravação/sessão,
evitando quadros quase idênticos entre partições. Não utilizar reconhecimento facial.
