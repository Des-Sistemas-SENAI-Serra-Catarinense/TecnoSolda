# Modelos

Nenhum peso treinado é fornecido ou carregado pelo protótipo.
Este diretório fica ignorado no Git, exceto este documento.

O futuro adaptador deverá usar pesos validados com as classes pessoa,
avental_soldagem, luva_soldagem, mascara_soldagem e respirador_valvula.
A posição da máscara e a associação de cada luva a uma mão exigem validação
específica. Não deduzir esquerda/direita apenas pela coordenada horizontal da imagem.
